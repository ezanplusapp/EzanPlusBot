# Ezan Plus — Privacy Policy

**Last updated:** September 4, 2026

## 1. Data Collection & Usage
Ezan Plus does not collect, sell, or rent any personal user data. Our automated publishing tools only utilize authorized API tokens to publish scheduled educational and spiritual content directly to our official social media channels.

## 2. Third-Party Integrations
Our services interact with official APIs provided by Meta (Instagram, Threads, Facebook), Google (YouTube Data API v3), and TikTok (Content Posting API). All access tokens are stored securely in local environment variables.

## 3. Contact
For questions regarding our privacy practices: https://github.com/ezanplusapp.
